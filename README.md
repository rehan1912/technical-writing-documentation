# Technical Writing Documentation

## Introduction

This repository contains documentation of the concepts and tools learned as part of the Technical Writing (TW) course.

The objective of this project is to understand and document tools used for technical documentation, scientific writing, presentations, collaborative writing, and version control.

## Topics Covered

1. [LaTeX](latex/latex.md)
2. [Beamer](beamer/beamer.md)
3. [Doxygen](doxygen/doxygen.md)
4. [Google Docs](google-docs/google-docs.md)
5. [Git](git/git.md)
6. [GitHub](github/github.md)

## Learning Objectives

- Understand technical documentation tools.
- Prepare documents using LaTeX.
- Create presentations using Beamer.
- Generate software documentation using Doxygen.
- Collaborate using Google Docs.
- Understand version control using Git.
- Manage repositories using GitHub.

## Conclusion

This project demonstrates the concepts and practical knowledge gained through the Technical Writing course.
